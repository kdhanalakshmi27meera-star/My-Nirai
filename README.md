# 🛍️ NIRAI – E-Commerce Website

NIRAI is a modern and responsive e-commerce website designed to provide a simple, attractive and user-friendly online shopping experience.

## ✨ Features

- 🛒 Shopping Cart
- ❤️ Wishlist
- 🔍 Product Search
- 📦 Product Categories
- 🖼️ Product Details
- ⭐ Product Reviews & Ratings
- 💰 Price & Discount Display
- 📱 Responsive Design
- 🎨 Interactive User Interface
- 💾 Local Storage Support

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
